## What's in it

From Yuri's `FORK-CHANGELOG.md` (2026-11-08):

- **Profile icons:** a doctor picks an operator or one of the game's 200 official icons, from the lobby's top bar or
  their own seat card. Everyone sees it on seat cards, the team panel, the draft and the results. AI teammates show their
  operator's icon and their operator's name in the page's language (`AI · Warfarin`). New `data/avatars.json`, built by
  `tools/build-avatars.mjs`.
- **Grand Alliance, 8-player rooms:** a human-only co-op room with two squads of 4, one shared pool and a shared leader
  fight. Off unless the server sets `SP_LARGE_ROOMS=1`.
- **Several servers, one game:** players connect to the nearest server, and alliance keys name their server. Off unless
  `SP_REGIONS` is set. The online count now updates at most once a minute.
- **Match chat:** text chat whose letters are last round's kills.
- **Host-browser bots:** bot prep, picks and bot battles can run in a human's browser Worker instead of on the server.
  All of it is off by default (`SP_BOT_EXECUTION=host`, `SP_BOT_BATTLES=host`).
- **Battle effects:** SilverAsh the Reignfrost's S3, Talulah's S3 sounds and fireballs, and 20 more operators whose
  attacks play the matching animation. Skill cast sounds follow the equipped skill.
- **Trait text:** about 25 traits now give their cap as "up to N stacks per battle", as the Chinese and the code have
  it, in every season.
- **Seven new outfits**, a faster first visit (what the screen needs loads first) and muted browser tests.

## Our side, adapted to Yuri's

- **Our tactic profiles run in the browser too.** Yuri's `server/match/botStrategyList.js` lists the strategies a browser
  Worker may load (`BUILTIN_BOTS`). It now also has `fish-level`, `fish-tier6` and `legacy-layered` (#129), so a seat
  with one of them keeps its profile when its prep runs in a browser. The Worker's module walk reaches
  `botTactics.js`, `botTacticsBasic.js` and `botTacticsLegacy.js` with no Node imports.
- **Host rehearsal:** Yuri removed the fork's host-rehearsal additions (`SP_BOT_REHEARSAL_HOST`, `botRehearsalHost` and
  the default-on delegation). This PR follows Yuri: `Match.js` now differs from Yuri's only by our lobby rules and match
  records. Our `bot.js` tunables from #129 stay, on top of Yuri's revert.
- **Rooms:** our Custom Lobby Modifications (`room.setRules`), the bot profile picker (`room.setBot`) and fill-with-bots
  (`room.fillBots`) sit beside Yuri's 8-seat rooms. The room footer keeps our rules bar next to Yuri's teammate search.
- **8-seat rooms stay human-only:** `room.addBot` refuses them. Our `room.fillBots` didn't, so a host could fill an
  8-seat room with AI. It now refuses too, and `test/large-room.test.js` checks it.
- **Our rules reach the bot's browser copy.** Yuri's host-browser bots play a seat's prep on a copy of the match
  (`botWorld.js`, `shadowMatch.js`). The copy didn't carry our lobby rules or the SPA-CC Risk bounties: every layout the
  bot rehearsed there failed to build (`this.waveBounties is not a function`, swallowed), so it fell back to its default
  layout. The copy now brings `lobbyRules` and the Patriot card's state, and borrows the Risk bounty methods. Yuri's
  parity tests caught it: the browser copy picked different layouts than the server.

## Fixes to Yuri's tests

Yuri's CI is red at `0f4b39c8`: every test shard fails, and the Python job hit a 504 while downloading Python. These
are the failures, fixed here so our CI passes:

- **Guards Yuri's new code missed:** loop-cap comments on two loops (`botRunner.js`, `match/botTasks.js`), three CSS
  size floors scaled by `--sp-ui` (the profile-icon picker and the chat bar), and the Grand Alliance e2e test's long wait
  through `waitForFunctionLong`.
- **The plugin bridge now refuses `rooms.*`:** Yuri's new `rooms.watch` (the room browser) is a client message a plugin
  frame could otherwise send (`shared/plugins/ui.js isIntentType`).
- **The match screen waits for `avatars`** like the other data files it reads (`GAME_FILES`), since profile icons show
  in matches.
- **Tests that didn't follow Yuri's changes:** the health callback test stubs the new `regions`; the random attack test
  gives each attack its own count, since one attack is now one pick; the Die clip test skips Amiya's and Dobermann's
  icon-only entries.
- **Ours:** our Patriot browser test is muted (`--mute-audio`), which Yuri's new guard asks of every browser launch.
- **Match host:** Yuri's broadcast that skips a sender, plus our match record, which the host process posts on its own.
- **Sounds:** our SPA-CC sound events play first, then Yuri's effect sounds.
