## How it was merged

- Merge base `0f4b39c8` (recorded in #130's squash message). 50 files conflicted: 24 goldens, 2 generated data files,
  24 code / doc / test files resolved by hand, keeping both sides.
- **`data/assets.json`:** merged entry by entry against `0f4b39c8`. The only clashes were the hash and stats; the hash
  is recomputed, `stats.files` / `stats.bytes` are base + our change + Yuri's change. Yuri's `merge:generated` agrees
  and rewrote `test/audio-pools-data.snapshot.json`. (Its "rebuild these units" warning comes from git's own merge
  base, which predates #130 since main is squash-only; against the real base, no entry clashed.)
- **`data/i18n/en.json`:** rebuilt with `build-i18n --lang en --refresh`. It also takes four official terms the EN game
  data has since renamed: "Dull" → "Sluggish", "Minimum DP" → "DP Lower Limit", "Necrosis / Corrosion / Nervous
  Impairment - Player" → "- Ally". No test or code names the old ones. ja / ko / zh-TW rebuild unchanged.
- **Goldens:** recomputed on the merged code for all four versions (`golden.mjs --update`, and `--version` for each
  older one).
- **`data/assets.json` final newline:** main's copy had none, and Yuri's new test requires the manifest to come back
  byte for byte through the merge tool. Rewritten with `tools/merge-generated.mjs`; only the newline changes.
- `build-data` changes nothing.
